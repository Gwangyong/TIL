# 2025.09.15 (월) - [Podoit] 키보드 Enter를 “완료” 표시로 변경하는 방법 → returnKeyType

podoit 타이머를 추가하면서 타이머 이름을 작성하는데 첫 화면처럼 키보드 오른쪽 아래가 그냥 **엔터(줄바꿈)이라서 살짝 헤맸다고 피드백**을 받았다. 

다른 앱들은 보통 “완료” 버튼 클릭 → 키보드 내리기 이런식으로 되었던 것 같다는 얘기를 해줬다.
피드백을 듣고 나도 본 적이 있었고, 실제로 그게 더 편해보였다.

내 파트가 아니었지만, 지인분이 주신 피드백이고 궁금하기도 해서 찾아보니 텍스트 필드에 `returnKeyType`을 `.done`로 지정하는 끝나는 매우 간단한 작업이었다. 

왼쪽이 지정하기 전, 우측이 지정한 이후이다.

이렇게 하면 “완료”를 통해 사용자가 자연스럽게 입력을 마무리할 수 있었다. 

하는김에 `returnKeyType`에는 뭐가 있을지도 찾아봤다.

- `.done`: 입력 완료 의도가 확실할 때. 이름, 한 줄 메모, 검색어 확정등에 적합하다.
- `.go`: 웹뷰나 외부 이동 같은 “바로 이동” 액션에 사용된다.
- `.search`: 검색창 전용. 돋보기 느낌
- `.send`: 메시지/코멘트 전송
- `.next`: 현재 필드에서 다음 필드로 포커스 이동
- `.continue`: 온보딩이나 단계 진행
- `.join`: 가입/참여
- `.route`: 길찾기
- `.emergencyCall`, `.google`: 특수 케이스 (거의 드물다고 한다)
- `.default`: 일반 엔터(줄바꿈 의도)

이처럼 생각보다 많았다.

### 추가) `.done`만으로는 “버튼 텍스트(UI)”만 바뀌고, 키보드를 내리는 동작은 자동으로 안된다.

`returnKeyType`은 말 그대로 “Return 버튼의 의미를 표시”하는 설정

- `.done` → “완료”라고 보여줌
- `.search` → “검색” 이라고 보여줌

다만, “버튼을 눌렀을 때 뭘 할지”는 개발자가 직접 정의하도록 되어있음

아래처럼 실제 동작은 따로 구현해줘야 한다. 

```swift
func textFieldShouldReturn(_ textField: UITextField) -> Bool {
    textField.resignFirstResponder() // 키보드 내리기
    return true
}
```

이 외에도, 키보드 관련해서 returnKeyType 말고도 자주 사용하는 옵션들이 있다고 하는데, 그것들과 위의 `returnKeyType`의 종류들을 실제로 했을때 어떻게 달라지는지는 다음에 정리해보자.
